# Griffin-derived 2D tracking split

`train_sequences.txt` contains 303 paired sequences from 73 training scenes. `val_sequences.txt` contains 67 paired sequences from 16 disjoint validation scenes. `difficult26_sequences.txt` identifies the 26 validation pairs meeting the manuscript's predeclared low-visibility or small-target conditions.

The lists identify membership only. The manuscript describes the derivation and evaluation criteria; the conversion scripts, derived images and annotations, and complete validation package are not included in this release. Griffin is a CARLA–AirSim co-simulation dataset and must be obtained from its original provider.
