# CVAC-Net dataset splits

This partial release contains only the sequence membership lists used for the CVAC-Net revision. The CVAC-Net model implementation, trained weights, and the complete Griffin 2D conversion package are being prepared for a later release. No images or annotations are redistributed.

| Dataset | Public lists | Scope |
|---|---|---|
| UGVT | [165 training pairs and 45 test pairs](ugvt_split/) | Exact paired-sequence membership used in the manuscript |
| Griffin-derived 2D tracking | [303 training pairs, 67 validation pairs, and Difficult26](griffin_2d_sot_protocol/) | Membership of the derived paired sequences |

The datasets must be obtained from their original providers under the applicable terms. These lists do not constitute a runnable training or evaluation package.
