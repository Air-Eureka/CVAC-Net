# CVAC-Net

This repository currently publishes **dataset split lists only** for the CVAC-Net Remote Sensing revision. The CVAC-Net model implementation, trained weights, and complete Griffin 2D conversion materials are not included at this stage.

- [UGVT: exact 165 training and 45 test paired sequences](reproducibility/CVAC-Net_RS_revision/ugvt_split/)
- [Griffin-derived 2D tracking: 303 training, 67 validation, and Difficult26 paired sequences](reproducibility/CVAC-Net_RS_revision/griffin_2d_sot_protocol/)

See the [split package README](reproducibility/CVAC-Net_RS_revision/README.md) for scope and usage. The underlying datasets must be obtained from their original providers.
